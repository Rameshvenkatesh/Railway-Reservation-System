🚆 Railway Reservation System (Python)

📌 Project Overview
This project is a simple Railway Reservation System developed using Python. It allows users to check available trains between locations and simulate a basic booking system.

🎯 Objective
To build a console-based application that demonstrates:
- Data handling using Python dictionaries
- User input handling
- Basic reservation logic

⚙️ Technologies Used
- Python

📊 Data Structure
The system uses predefined data stored in dictionaries:
- Train routes (source → destination)
- Available train names

🔄 Workflow
User enters source & destination  
⬇  
System checks available trains  
⬇  
Displays train list  

🧪 Features
- Search trains between two locations  
- Display available train options  
- Simple interface  

📈 Key Learnings
- Python dictionaries and lists  
- Conditional statements  
- User input handling  

⚠️ Challenges Faced
- Handling invalid inputs  
- Structuring data  

🚀 Future Enhancements
- Add booking system  
- Connect with SQL database  
- Convert into web app using Django

🚀 Conclusion
This project demonstrates the implementation of a basic Railway Reservation System using Python. It highlights the use of data structures like dictionaries and fundamental programming concepts such as conditional statements and user input handling.

Overall, this project helped in strengthening core Python skills and understanding how real-world systems can be simulated using simple logic. It also lays a strong foundation for building more advanced applications in the future.
